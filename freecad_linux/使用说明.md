# FreeCAD 版 AutoCAD MCP 服务器（Easy-MCP-AutoCad 的 Ubuntu 移植）

原项目 https://github.com/zh19980811/Easy-MCP-AutoCad 是 Windows + AutoCAD COM 专用，Linux 跑不了。
本项目把它的 19 个工具 1:1 移植到 FreeCAD 1.1.4 后端，另加 save_drawing / export_dxf（共 21 个工具），
让 LLM 通过 MCP 协议用自然语言在 FreeCAD 里画图、扫描、查询、高亮、存盘。

## 目录结构（~/hermes-home/tools/freecad/）

- bridge.py                FreeCAD 内部 TCP 桥接服务器（127.0.0.1:8765，JSON 行协议）
- server_freecad.py        MCP 服务器（stdio），连 bridge 执行几何操作 + 管理 SQLite
- start_bridge_headless.sh 无头模式一键启动 bridge
- FreeCAD_1.1.4-*.AppImage FreeCAD 本体（GUI 模式用这个）
- squashfs-root/            AppImage 解包产物（含无头二进制 freecadcmd）
- autocad_data.db           实体数据库（cad_elements / text_patterns 两张表）

## 架构

```
LLM (Claude 等) ──MCP/stdio──> server_freecad.py ──TCP 8765──> bridge.py ──> FreeCAD API
                                   │                                  │
                                   └── SQLite autocad_data.db        └── 图层=附加属性
```

## 启动方式

### 方式一：无头模式（测试/服务器，不需要显示器）

```bash
~/hermes-home/tools/freecad/start_bridge_headless.sh     # 终端 A：起 bridge（常驻）
cd ~/hermes-home/tools/freecad && ~/venvs/autocad/bin/python server_freecad.py   # 终端 B：MCP 服务器（stdio）
```

停止：kill 掉 start_bridge_headless.sh 的进程即可（脚本带 trap，会连带清理 freecadcmd）。

### 方式二：FreeCAD GUI 模式（能实时看到画的图）

1. 启动 FreeCAD：`~/hermes-home/tools/freecad/FreeCAD_1.1.4-Linux-x86_64-py311.AppImage`
2. 菜单 视图 → 面板 → Python 控制台，粘贴执行：
   ```python
   exec(open('/home/why/hermes-home/tools/freecad/bridge.py').read())
   ```
   （也可以 宏 → 宏… → 创建，把上面这行存成宏随时跑）
3. 控制台出现 "bridge 已启动，监听 127.0.0.1:8765" 即成功；FreeCAD 窗口继续正常使用。
4. 另开终端启动 MCP 服务器（同上）。

注意：高亮/颜色只在 GUI 模式下可见（无头模式没有视图对象）。

### 接到 MCP 客户端

server_freecad.py 是标准 stdio MCP 服务器。例如 Claude Desktop 的配置：

```json
{
  "mcpServers": {
    "freecad": {
      "command": "/home/why/venvs/autocad/bin/python",
      "args": ["/home/why/hermes-home/tools/freecad/server_freecad.py"],
      "cwd": "/home/why/hermes-home/tools/freecad"
    }
  }
}
```

## 21 个工具

绘图：create_new_drawing, draw_line, draw_circle, draw_polyline, draw_rectangle, draw_text, create_layer
扫描/高亮：scan_all_entities, highlight_entity, count_text_patterns, highlight_text_matches
数据库：get_all_tables, get_table_schema, execute_query, query_and_highlight
编辑：move_entity, rotate_entity, copy_entity, draw_device_connection
存盘：save_drawing（FCStd）, export_dxf

## 与原 AutoCAD 版的差异

| 项 | 原版 | 本版 |
|---|---|---|
| 后端 | AutoCAD COM (pywin32) | FreeCAD Part API |
| 句柄 | AutoCAD Handle | FreeCAD 对象 Name（如 Line001） |
| 图层 | 原生图层 | 文档组 LAYER_<名> + 对象附加属性 Layer |
| 颜色 | AutoCAD 索引色 | 仅 GUI 模式可见（ShapeColor） |
| 数据库 type 字段 | AcDbLine 等 | FreeCAD TypeId（Part::Line 等，scan 与 draw 一致） |
| 存盘 | AutoCAD 自己存 | 必须用 save_drawing / export_dxf |
| 文字 | AddText | App::Annotation（1.1 无 FontSize，height 仅入库） |

## 已知局限

- 无头模式保存的 FCStd 本来缺 GuiDocument.xml（视图状态），GUI 打开时所有对象 Visibility=False（树里有、视图空白）。已修：save 命令保存后自动按 templates/ 的视图模板注入 Visibility=true（离屏 GUI 实测 17 对象全可见）。新增对象类型没有模板时会走 vp_fallback.xml（可能仍不可见，需在 GUI 里选中对象按空格）。
- rotate 绕 z 轴、角度单位度；绕 base_point 旋转，非绕原点时数学正确但需注意语义。
- Part::Feature（矩形/多段线）在 scan_all 里的 properties 是离散采样点（每边 8 点），非原始顶点。
- draw_device_connection 需要 DB 里先有 type='CustomDevice' 且 properties.label 匹配的实体（本套工具暂未提供自定义设备创建工具，可从 execute_query 手动插）。
- DXF 导出（importDXF）两个怪癖：Part 多边形会同时导出为 LWPOLYLINE 和逐条 LINE 线段（行数会多于实体数）；App::Annotation 文字不导出（FCStd 里都在，DXF 里没有）。需要精确 DXF 请以 FCStd 为准另找转换工具。
- 无头模式颜色/高亮命令正常返回但不可见。
